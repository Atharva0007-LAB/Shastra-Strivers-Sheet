### Problem 140: Count Occurrences in a Sorted Array
**Difficulty:** Easy | **Tags:** Array, Binary Search

**Problem Statement:**
Given a sorted array `arr` of `n` integers and an integer `x`, write a program to find the number of occurrences of `x` in `arr`.

### Input Format
* The first line contains two integers `n` and `x`.
* The second line contains `n` space-separated integers representing `arr`.

### Output Format
* Print a single integer representing the count of occurrences of `x`.

### Constraints
* 1 <= n <= 10^5
* 1 <= arr[i], x <= 10^9
* `arr` is sorted in non-decreasing order.

### Example
#### Input:
```text
7 2
1 1 2 2 2 2 3
```

#### Output:
```text
4
```

#### Explanation:
2 appears 4 times in the array (from index 2 to 5).
