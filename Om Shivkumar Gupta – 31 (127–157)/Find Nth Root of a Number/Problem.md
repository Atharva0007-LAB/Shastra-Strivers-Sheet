### Problem 142: Find Nth Root of a Number
**Difficulty:** Easy | **Tags:** Math, Binary Search

**Problem Statement:**
Given two numbers `n` and `m`, find the `n`-th root of `m`. If the `n`-th root is not an integer, return `-1`.

### Input Format
* The first line contains two integers `n` and `m`.

### Output Format
* Print a single integer representing the `n`-th root if it is an integer, otherwise `-1`.

### Constraints
* 1 <= n <= 30
* 1 <= m <= 10^9

### Example
#### Input:
```text
3 27
```

#### Output:
```text
3
```

#### Explanation:
3^3 = 27, so the 3rd root of 27 is 3.
