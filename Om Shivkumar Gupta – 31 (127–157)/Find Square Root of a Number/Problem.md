### Problem 141: Find Square Root of a Number
**Difficulty:** Easy | **Tags:** Math, Binary Search

**Problem Statement:**
Given an integer `n`, find the square root of `n`. If `n` is not a perfect square, return `floor(sqrt(n))`.

### Input Format
* The first line contains a single integer `n`.

### Output Format
* Print a single integer representing the floor of square root of `n`.

### Constraints
* 0 <= n <= 10^9

### Example
#### Input:
```text
28
```

#### Output:
```text
5
```

#### Explanation:
The square root of 28 is approximately 5.2915... whose floor value is 5.
