### Problem 153: Generate Parentheses
**Difficulty:** Medium | **Tags:** String, Backtracking

**Problem Statement:**
Given `N` pairs of parentheses, write a function to generate all combinations of well-formed parentheses.

Print each valid combination on a separate line, sorted in lexicographical order.

### Input Format
* A single line containing an integer `N`.

### Output Format
* Print each valid string of well-formed parentheses on a new line.

### Constraints
* 1 <= N <= 8

### Example
#### Input:
```text
3
```

#### Output:
```text
((()))
(()())
(())()
()(())
()()()
```

#### Explanation
* All 5 valid combinations of 3 pairs of parentheses are generated in lexicographical order.
