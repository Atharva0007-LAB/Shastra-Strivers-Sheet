# Sort an Array of 0's, 1's and 2's

**Difficulty:** Medium  
**Tags:** Arrays, Sorting, Two Pointers, Dutch National Flag Algorithm

## Problem Statement

You are given an array `nums` consisting of `0`, `1`, and `2`.
Sort the array in non-decreasing order so that all 0s appear first,
followed by all 1s, and then all 2s.

You must solve this problem without using a built-in sorting function.

## Input Format

- The first line contains an integer N, representing the size of the array.
- The second line contains N space-separated integers, each of which is
  either 0, 1, or 2.

## Output Format

Print the sorted array as N space-separated integers.

## Constraints

- 1 <= N <= 10^5
- nums[i] is either 0, 1, or 2.

### Input
```text
6
2 0 2 1 1 0
